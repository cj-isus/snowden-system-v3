# Сайт продукта и базы знаний

Сайт: **https://cj-isus.github.io/snowden-system-v3/**.

Единственный редактируемый источник базы знаний — `docs/theory/`,
`docs/planning/knowledge-application/` и `docs/KNOWLEDGE-BASE.md`.
Сайт читает только их версию из Git. Непереданные изменения других владельцев,
служебные артефакты, настройки Obsidian, код и данные приложения в экспорт не входят.

Главная — лендинг продукта. Граф доступен по `/graph`, установщики и сведения о
версиях — по `/downloads`, порядок установки и восстановления — по `/release-guide`.
Страницы продукта находятся в `knowledge-site/content/`, статические компоненты —
в `knowledge-site/components/`. Они не дублируют канонические материалы теории.

## Публикация приложений

`releases.json` — единственный каталог публичных загрузок. Сейчас список `releases`
пуст: наличие локального EXE/APK, завершение разработки или работа отдельного
профиля не являются разрешением на выпуск. Статус Android на 6 ноября передан
владельцем; термин TTT сохранён без догадки о конкретном протоколе.

После приёмки приложения его владелец публикует файл в GitHub Releases. Затем
сопровождающий сайта сверяет **реальный публичный** release/asset, его размер,
байты SHA-256, версию, совместимость и примечания. Только после этого добавляет
запись в `releases` со следующими полями:

- `platform`: `windows` или `android`;
- `version`, `channel`: `stable` или `preview`, `publishedAt`: дата `YYYY-MM-DD`;
- `url`: точный HTTPS URL EXE/APK в Releases этого репозитория;
- `notesUrl`: URL тега того же выпуска;
- `sizeBytes`, `sha256`, `requirements`: размер, сумма и требования к ОС/архитектуре.

Первый элемент платформы выбирается для карточки, остальные остаются в истории.
Для платформы с выпуском обновить также `state`/`label`/`summary`/`next`, дату
`updatedAt`, текст главной и инструкции по миграции. Не указывать непроверенную
поддержку автообновления или подписи. Документировать фактический механизм.

Сборка проверяет форму каталога, платформы, контрольные суммы, расширения и
совпадение тегов ссылок. Это проверка метаданных: она **не скачивает установщик**,
не подтверждает байты удалённого файла, подпись или работу VPN. Сверка публичного
asset перед изменением каталога обязательна. Сайт не содержит загрузчика файлов,
серверных секретов или механизма самостоятельной публикации приложений.

Основа — [Quartz 4.5.2](https://github.com/jackyzha0/quartz/tree/d25a6eabf96751ffca56f8a8139272def7a65041),
MIT. Та же закреплённая версия использовалась как источник графа в отдельной работе
над папками. Лицензия движка сохранена в `LICENSE-Quartz.txt`.
Mermaid закреплён отдельным lockfile и собирается в локальные ресурсы сайта;
формулы отображает MathJax SVG. Аналитика и внешняя загрузка шрифтов отключены.

Граф сохраняет оболочку Quartz. Раскладку считает закреплённый D3 при сборке,
а браузер рисует Canvas2D только после действия/resize. В скрытой вкладке и вне
экрана отрисовка приостановлена. Размер и плотность подписей зависят от масштаба;
непересекающиеся подписи и полное название выбранной заметки доступны без
постоянной физики или GPU-текстур. Дерево и граф читают облегчённый navigation index;
полный текст и FlexSearch заполняются только при открытии поиска.

## Как обновляется сайт

1. Править канонические Markdown-файлы в `docs`.
2. Публиковать проверенные изменения в `main`.
3. Workflow `knowledge-pages.yml` экспортирует содержимое, собирает Quartz
   и публикует артефакт GitHub Pages.

Экспорт не меняет исходные заметки. Заголовок и ссылки адаптируются для сайта,
а у каждой статьи остаётся ссылка на исходный Markdown той же версии.
Авторские оригиналы доступны отдельной веткой дерева.

`upstream.json` фиксирует движок. При его обновлении нужно согласованно менять
ref в workflow и проверять локальную адаптацию; автоматического `latest` нет.

## Изолированная сборка

В чистой копии закреплённого Quartz установить его lockfile через `npm ci --ignore-scripts`,
а runtime — через `npm ci --prefix knowledge-site/runtime --ignore-scripts`.
Далее:

```text
node knowledge-site/export-content.mjs --repository . --ref HEAD --out <quartz>/site-content --quartz <quartz>
node knowledge-site/apply-site.mjs --quartz <quartz>
node knowledge-site/build-site.mjs --quartz <quartz>
```

Это сборка читательского сайта. Она не запускает проверки, сборки или сетевой runtime VPN.
