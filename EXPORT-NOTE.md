# О публичной копии репозитория

Это экспорт рабочего дерева SNOWDEN-SYSTEM-V3, подготовленный для публикации.
Инфраструктурные идентификаторы заменены плейсхолдерами (документация RFC 2606/5737
и синтетические фикстуры). Все реальные значения остаются только в локальном,
не-экспортируемом окружении (gitignored: `secrets/`, `vps.env`, `.tmp/`).

## Карта подстановок

| В репо | Что это | Реальное значение |
|---|---|---|
| `203.0.113.10` | IP сервера (TEST-NET-3) | локальный `vps.env` → `VPS_HOST` |
| `192.0.2.44` / `192.0.2.55` / `192.0.2.66` | ISP-IP владельца в evidence-доках | только локально |
| `vpn.example.com` | Имя зоны сервера | Cloudflare (вне репо) |
| `legacy.example.com` | Прежняя зона в истории доков | Cloudflare (вне репо) |
| `00000000-0000-4000-8000-00000000000c` | UUID канала C (фикстура) | клиентский DPAPI-vault / локальные secrets |
| `AAAA…A` (43 симв.) | Reality public key (заглушка X25519-формата) | генерируется `reality x25519` при деплое |
| `0123456c` | Reality short_id (фикстура) | локальные secrets |
| `000…0` (CF id/hex) | Идентификаторы Cloudflare в evidence | Cloudflare (вне репо) |

Пути к реальным секретам в коде не хардкодятся: клиент читает их из
DPAPI-хранилища, серверные шаблоны (`configs/singbox/server-combined.json`)
используют `{{PLACEHOLDER}}`, подстановка — `configs/deploy-vps.sh` из
gitignored-каталога `secrets/channels/`.

Юнит-тесты проходят на фикстурах; live-тесты (тег `live`) требуют реального
окружения и из чистого клона осмысленно падают-пропускаются (skipped/fail-closed).
