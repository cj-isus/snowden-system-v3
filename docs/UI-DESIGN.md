# UI: страницы и компонентные границы

Отдельный дизайн-проход текущего запроса. Требования и статусы — PLAN OFF-08;
здесь устройство интерфейса и критерии review, без второго backlog.

## Общая композиция

Тёмная поверхность, оранжевый акцент действий и активной навигации, зелёный
только для положительного результата. Сначала состояние и нужное действие,
затем детали. Вложенные рамки, повторные сводки и мелкие декоративные подписи
не должны вытеснять информацию.

`navigation.ts` определяет разделы, страницы, названия и принадлежность.
NavRail показывает только разделы. ContextTabs — только страницы выбранного
раздела; для единственной страницы полосы табов нет. Переход из поиска
выбирает нужный раздел; возврат через меню сохраняет последний его подраздел.
Табы имеют доступные имена, roving tabindex, стрелки, Home/End.

SectionHeader обозначает раздел; PageHeading объясняет задачу конкретной
страницы. CommandPalette и NotificationPanel используют DialogFrame для
фокуса, Escape и возврата к вызвавшему элементу. App.vue связывает навигацию
и страницы, а не содержит реализацию каждого окна.

## Проход страниц

| Страница | Приоритет и изменения |
|---|---|
| Главная | Подключение/отключение, фактический scope SOCKS/TUN, канал и probe. Удалены скрытые копии журнала и списка каналов. Управление компактнее. |
| Контекст сети | Факты в строках, перенос длинных значений, явное обновление, отдельная доступность источников. |
| Адаптация | Состояние сторожа → здоровье каналов → независимость. Исправлена ошибочная CSS группа, превращавшая целые панели в одну строку. Длинные пары каналов переносятся. |
| Телеметрия | Разделены адаптер и ядро; реальное окно наблюдения. До двух samples графика нет. Смена адаптера/сброс начинает новое окно. Таблица соединений прокручивается внутри своего блока. |
| Восстановление | Причина состояния и явное действие исправления; прокси как пары ключ/значение. Listener не объявляется доказательством защищённого VPN. |
| Каналы | Реестр, поиск, статус и действие в одной таблице; отдельное «ничего не найдено» после фильтра. |
| Проверки | Единый список вместо россыпи карточек; общий lock всего batch, отдельные unknown/fail/pass/running/skipped. Полностью пропущенный тест не получает зелёный PASS. |
| Журнал | Фильтры и рабочая область лога; пустой журнал отличается от пустой выборки. Успех копирования появляется только после ответа Clipboard API. |
| Система | Профиль и автозапуск; перенос/обновления вынесены в ProfileTransfer и ApplicationUpdate. Удалена дублирующая таблица секретов. |
| Секреты | Единый список метаданных и форма; подтверждение значения обязательно и для нового, и для существующего слота. Кнопка копирования названа по действию. |

## Владение данными

- `backendState`: одна подписка на Wails, owner generation и защита от
  устаревшего bootstrap; Start/Switch не дублируются, Stop имеет приоритет.
- `polling`: один запрос за раз, следующий опрос после ответа; unmount отзывает
  право публикации. Wails Promise нельзя физически отменить средствами UI.
- `infoFacts`: общий сборщик сети/сторожа с учётом потребителей.
- Views используют API facade; компоненты не импортируют Go bindings напрямую.
- ProfileTransfer связывает preview с точными данными и фразой; изменение
  входов отзывает preview. Это дополняет, а не заменяет серверную проверку.

## Приёмка

Проверять каждую страницу с данными и без backend, ширины из TESTING.md,
длинные значения, клавиатуру, основные действия, фокус и отсутствие общего
горизонтального скролла. Внутренние таблицы и табы могут прокручиваться.
Reduced motion отключает декоративные переходы. Browser screenshots — review
синтетического интерфейса; нативный WebView2/DPI и фактическая защита проверяются
отдельно. Субъективная оценка «на высшем уровне» не заменяется числом тестов.
