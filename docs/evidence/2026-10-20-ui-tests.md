# V2-098 — повторяемые тесты и UI

Дата: 2026-10-20. Среда: Windows, Node 22.21.1, Go 1.26.7.
Запрос владельца: качественные тесты, отдельная проработка всех страниц,
читаемый компонентный код. Работа офлайн, без SSH/VPS/admin/системной сети.

## Результат

- Добавлены 47 unit/component тестов в 9 файлах, 10 браузерных сценариев и
  два Go regression для ошибок cleanup/barrier с явным recovery.
- Покрыты отрицательные исходы: старый snapshot после event, отмена Start
  через Stop, повторные действия, публикация после unmount, ошибка источника,
  изменённый preview импорта, несогласованное подтверждение секрета,
  сброс счётчика, nil slice, unknown и полностью skipped результат.
- Исправлены дефекты, найденные проверками: наложение polling, stale bootstrap,
  потеря event subscription при частичном сбое, batch lock диагностики,
  ложный PASS для skipped, responsive flex на странице адаптации,
  Node resolution до постороннего package.json с BOM.
- UI: единый registry меню/подразделов; App — composition root. Поиск,
  уведомления, модальные окна, перенос профиля и обновления выделены в
  осмысленные компоненты. Все 10 views прошли отдельный дизайн-проход.
  Постраничные решения и владение данными — [UI-DESIGN](../UI-DESIGN.md).

## Границы и остаток

Проверен локальный код и synthetic UI. Не проверялись текущий VPS, реальный
protected egress/failover, WFP arbitration, crash/reboot, Windows DNS/UDP/IPv6
и native WebView2 DPI 125/150/200%. CSS размеры не заменяют эти проверки.
Полный fault matrix/transactional import/update остаётся в OFF-02…06.
Race не выполнялся при CGO=0. Новый EXE/NSIS не собирался: прежний EXE V2-097
не содержит последующие UI изменения. Production readiness не заявляется.
