## Краткий результат

Ошибки прежнего R03-17 независимо разобраны математически. При произвольной
зависимости действует суммарная граница, а не произведение. Заранее известное
W не необходимо: достаточно conditional anytime validity при фактическом
выборе процедуры и предсказуемого счётного расхода с pathwise суммой ≤δ.
«Один физический кредит за успех» при independent q<1 имеет конечное
ожидание, но не hard cap; q нельзя отождествить с α. Журнал сам не доказывает
completeness или registration-before-observation. Reuse проверен после
доказательства, по конкретным функциям и лицензиям.

## R03-010-A — корректная композиция ошибок

| Поле | Содержание |
|---|---|
| Вопрос | Когда случайное число адаптивных запусков сохраняет lifetime FWER? |
| Вывод | Если admission/α_j/model/target выбраны до собственных данных, E[1_Ej\|H_j^-]≤A_jα_j и ΣA_jα_j≤δ a.s., тогда P(∃j:E_j)≤δ по tower property, union и монотонной сходимости. W может быть неизвестно, результаты — задержаны |
| Тип evidence | Ручное элементарное доказательство; primary definition/theorem comparison P1/P2/P4 |
| Коррекция baseline | Для фиксированного W без independence: min(1,Σα_j); product только при independent error events. Simultaneous FWER сохраняется при выборе поднабора уже покрытых claims; FDR arbitrary опубликованного subset — нет |
| Контрпример | min двух просмотренных independent uniform p: одна зарегистрированная α=δ проверка имеет error=1−(1−δ)^2>δ; accountant сам не чинит conditional validity |
| Предпосылки | Смысл family/null/estimand и модель фильтрации заданы; condition учитывает реально доступные partial/late данные; нет invented costs/drift/priors |
| Предел | Не доказаны producer validity текущего advisor, causal/target-task transfer, optional-stopping FDR произвольной процедуры или inference по finish-order-only выборке |
| Где доказательство | REPORT-010 §§2–3.6; P1 (1), Lemma 3; P2 Theorem 1 independence/monotonicity для FDR; P4 conditional mean/Ville |

## R03-010-B — кредитная модель

| Поле | Содержание |
|---|---|
| Вопрос | Когда пополнение физических кредитов даёт конечное ожидание и что из него следует? |
| Вывод | A_{t+1}=A_t−1+bS_t. Для independent S_t~Bernoulli(q), b=1,q<1: E[T]=W/(1−q), E[successes]=Wq/(1−q), drift=q−1<0. b≥2: subcritical bq<1 даёт E[T]=W/(1−bq); critical mean может быть бесконечным без гарантии вечной работы |
| Особая граница | В independent all-null b=1 модели FWER=1−(1−α)^W; при W=1 FWER=α даже при случайном T и pathwise сумме repeated α выше α. A1/A2 — достаточные, не необходимые условия |
| Контрпример | q=1,b=1 — бесконечная работа; 0<q<1 — конечное ожидание при неограниченном support T. Следовательно finite E[T] не hard bound |
| Предел | q — не α для реального полезного task success; dependency/nonstationarity/reward policies меняют модель. Никаких actual measurements/симуляций |
| Где доказательство | REPORT-010 §4 |
