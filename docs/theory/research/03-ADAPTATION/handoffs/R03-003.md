## Главные ручные результаты

1. Четыре nuisance bits могут быть менее полезны для действия, чем один нужный.
2. XOR: каждый отдельный тест имеет zero gross one-step value, пара полезна.
3. D3 substitution proof даёт scoped deterministic dominance; marginal accuracy
   или другой URL не дают этого proof.
4. Два мира с одинаковыми ответами **всех доступных** tests, но разными нужными
   действиями неразличимы любым конечным causal plan. Нужен новый control.
5. Для finite static minimax model: `Rπ≥c−+max_w min_a L(a,w)` при uniform cost
   lower bound. Это условный stop bound, не expected-benefit theorem.
6. A=[0,10],B=[6,6]: perfect information не улучшает worst case6, но при fair
   prior снижает expected loss5→3. Выбор objective нельзя скрывать.
7. При E=10,t=8,C∈[1,4] результат возможен в9, хотя worst case12. Upper bound
   не позволяет гарантировать, но не доказывает невозможность.

Числа условные, не продуктовые измерения. Нет выдуманных costs/priors/dependence.
