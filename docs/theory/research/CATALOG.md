# Каталог исследовательских пакетов

Пакеты сгруппированы по направлениям R02–R06. Каждая строка связывает handoff с точными REPORT/SOURCES и применимым решением; новый раздел внутри накопительного REPORT не создаёт пакет и не меняет научный статус автоматически.

[Общая карта](../KNOWLEDGE-MAP.md) · [ECH, измерения и доверие: содержание](NINE-KNOWLEDGE.md) · [Полный реестр решений](REVIEW-REGISTER.md) · [JSON](CATALOG.json)

## Как читать

Handoff → точный REPORT/SOURCES → применимая рецензия и её область. Накопительный REPORT может содержать несколько пакетов; scoped решение относится к названному вопросу, а не ко всему пакету или product execution. [Исходная карта разделов](../CONTENTS.json) сохранена отдельно.
