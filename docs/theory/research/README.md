REPORT — аргумент; SOURCES — первоисточники, версии и глубина чтения;
review — решение только в названных предпосылках. Авторская готовность не означает принятие вывода.
Source/model evidence не заменяет native/device/live проверку. Все эти границы
сохраняются в новом [плане применения](../../planning/knowledge-application/README.md).

Слова «текущий» и `current` в датированных аргументах относятся к указанному
срезу исходников. Состояние реализации сегодня ведут владельцы в
[плане ПК](../../planning/knowledge-application/PC-PLAN.md) и
[плане Android](../../planning/knowledge-application/ANDROID-PLAN.md).
Старые TH/AND/COM-координаты — происхождение предложения, не новая очередь работ.
