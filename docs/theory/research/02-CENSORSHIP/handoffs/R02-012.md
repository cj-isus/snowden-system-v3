# R02-012 — паспорт решётки доменов отказа на барьере IP/ASN/allowlist

| Поле | Значение |
|---|---|
| ID / вопрос | **R02-22**: какие кандидаты реально выживают при возведённом барьере IP/подсеть/ASN-репутация + allowlist, и какие домены отказа у них общие? |
| Короткий вывод | Каналы с общим адресом, origin или управляющей платформой могут иметь общую причину отказа. Решётка полезна как условная модель зависимостей, но не устанавливает вероятности доступности, обязательный набор каналов или единственный работающий способ обхода |
| Статус | Авторский **READY_FOR_REVIEW**, срез 26.10.2026; количественные расширения ограничены принятой рецензией R02-014-A. Остальной пакет не принят целиком |
| Evidence | Датированные публикации, научная работа и отдельное полевое обсуждение; разные виды свидетельств. Логическая модель, без собственных сетевых измерений |
| Область / дата | Датированные сообщения о РФ; представительная региональная/mobile-fixed карта и механизм всех эпизодов не установлены |
| Предпосылки | Проценты опубликованы без установленной методики и названной лаборатории; даже атрибуция конкретному сервису не установлена. Разность 469−258 не доказывает число новых уникальных блокировок |
| Сильная альтернатива | Разные протоколы не гарантируют независимости: общий origin или UDP-путь сохраняет зависимость. Обратное тоже важно: общая метка ASN/CDN ещё не доказывает, что все пути откажут одинаково |
| Ready reuse | Составить граф общих зависимостей текущих каналов; один VPS сохраняет общий origin. CDN меняет часть пути, но требует отдельной совместимости, доверия и оценки стоимости; второй сервер моделью не предписан |
| Reject / цена | Для платформенного реле учитывать API, техническую доступность, доверие, лимиты, стоимость и правила владельца. Правовые выводы не прошли отдельной проверки |
| Следствие для системы | Адресат FR-owner: портфель каналов оценивается по покрытию доменов отказа; тесты переключения — по сценариям D2/D3/D4/D5 отдельно |
| Что ещё проверить | §5 REPORT-012: региональные замеры, независимая проверка заявок, мониторинг подсетевых списков — NOT_RUN |
