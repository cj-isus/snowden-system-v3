## Сильнейшее ограничение и вопросы R03/R04/R05

Ни один прочитанный источник не даёт current RF efficacy для выбранной совместной
модели/наших сборок. GotaTun data-pattern defence не скрывает его handshake этим
hook; Naive cover может fail без отказа Connect; finite-prefix protection не
аттестует все поздние streams. Сравнительного победителя пока нет.

- **R03:** joint/selected-probe correlation; endpoint vs flow unit; requested /
  queued / replaced / emitted / useful outcome; не новый authority score.
- **R04:** records vs packets, extra bytes vs wire costs, quota/queue age/radio;
  ручной предел continuous cover не означает необходимость constant-rate для всех.
- **R05:** machine provenance/limits, epoch cancellation, hard adapter protection;
  shaper bypass не bypass WFP/TUN; отказ cover не разрешает direct.

Связь с существующими задачами: TH-05/06, E-04, AND-01/18, COM-18.
Очередность — сначала scope/контракт и P0, затем один ограниченный comparative
spike; programmable shaping только при доказанной пользе поверх baseline.
