# R02-010 — паспорт доступности ready session binding

| Поле | Значение |
|---|---|
| ID / вопрос | **R02-19**: доступен ли готовый exporter через actual common TLS adapter? |
| Короткий вывод | uTLS native exporter существует, но core ConnectionState literal теряет private callback; HandshakeComplete metadata не доказывает usable exporter capability |
| Статус | **READY_FOR_REVIEW**, не current app crash/exploit/ACCEPTED |
| Evidence | Pinned source/cache/callers + RFC9266/8446 + local Go1.26.7 reference. Никакого exporter/crypto/TLS execution |
| Область / дата | 26 октября2026, core1.13.19/b5ebaa1f…, uTLS1.8.4/cf49b086…, sing0.8.13 common Conn; consumers в backend/corebridge не найдены |
| Предпосылки | Future consumer использует standard state из uTLS wrapper; exact artifact и negotiated TLS/identity ещё не установлены |
| Сильная альтернатива | Native uTLS state умеет EKM, STD path сохраняет реальный state. Это seam одного adapter, не отсутствие TLS exporters вообще |
| Ready reuse | Go/uTLS native primitives BSD-3-Clause через typed supported/error capability; core GPL-3.0-or-later. Auth profile/termination/cardinality и migration обязательны |
| Reject / цена | Нельзя экспортировать donor C↔D secret у relay E, заменить binding SNI/certHash или использовать RFC9266 bytes как cipher key; несколько auth instances на carrier требуют совместимого profile |
| Actual resumption | В traced constructors cache не установлен; ShadowTLS helper его не копирует; VLESS lazy header/WS early_data не TLS0RTT. Broad0RTT finding отвергнут |
| Что ещё проверить | REPORT010 §5 **NOT_RUN**: STD/uTLS capability, peers/epochs, mux cardinality, cache/1RTT/0RTT, native/wire |
| Sources/review | [REPORT](../REPORT-010.md), [SOURCES](../SOURCES-010.md), LOCAL/INDEX/REVIEW; self-review не independent acceptance |

Не предлагать новый cipher/auth protocol ради availability API. Existing real inner
TLS уже даёт нужный data-session boundary при выполненных условиях009; exporter
нужен только выбранному channel-bound consumer, которого сейчас не обнаружено.
