# R02-008 — anti-probing first-record boundary

26 октября2026 · **READY_FOR_REVIEW**.
[REPORT](../REPORT-008.md) · [SOURCES](../SOURCES-008.md).

**R02-17:** ShadowTLS server caller подаёт Go TLS parser только первый record.
Full CH в одном record при bad auth может relay к donor; тот же корректный CH
в нескольких records получает local EOF/parse error до donor fallback. Это TLS
record fragmentation, не TCP segmentation. Source/manual counterexample;
уникальный RF detector/точный FIN-RST/timing/native behavior не заявлены.

Reference parser source Go1.26.7 прочитан с установки без выполнения; production
binary/toolchain не аттестован. Donor control и false positives обязательны.
Resource budgets на message/connection/process+donor pool различать: bounded
record не ограничивает concurrent state, HMAC user loop или donor sockets.

Reuse/adapt зрелый parser и existing CachedConn/prefix relay с bounded reassembly,
canonical auth transcript и both-end compatibility. Не делать TLS parser заново.
Предложенные finite cases **NOT_RUN**, no tests/crypto/build/native/live.
Дальнейший research не продлевать после10:03:26Z; сохранить final inputs/остаток.
