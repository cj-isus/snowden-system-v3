## Контраргументы, которые нельзя потерять

- Наличие Vision source не доказывает правильную сборку/native wrappers/сервер;
  unsafe/reflection и semantics требуют отдельной конечной приёмки.
- HTTP/1.1 WS и Go UA встречаются у легитимных клиентов; это не готовый детектор.
- Разные ветки допуска не доказывают remote oracle; blind prober и PSK-known
  prober должны иметь разные controls.
- Протоколы с общим VPS не покрывают его outage; CDN может пережить блок direct
  entry IP при доступном origin со стороны CDN, но не outage origin.
- P08/P09 — полевая гипотеза конкретных наблюдателей; Китай и старый IMC не
  устанавливают текущий nationwide механизм РФ.

## Смежные вопросы, без присвоения их разработки

- **R03:** неизвестная стадия/credential-class mismatch не получает causal label DPI;
  passport не должен становиться scalar safe/independent authority.
- **R04:** будущий shaping меняет overhead; собственный unsafe Vision path нужно
  оценивать отдельно от no-flow, без переноса чужих performance процентов.
- **R05:** разные уровни admission и secret custody; никакой защиты не ослаблять
  ради cover. CensorLess private-mode crypto artifact не проверен.
- **R06:** резерв origin/account/carrier привязать к конкретному пользовательскому
  отказу; serverless cost не переносить на один VPS без модели.
