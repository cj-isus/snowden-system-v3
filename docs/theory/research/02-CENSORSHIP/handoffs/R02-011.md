# R02-011 — паспорт early-data/replay границы HY2 и ShadowTLS conversion

| Поле | Значение |
|---|---|
| ID / вопрос | **R02-20**: экспонирован ли HY2-auth через TLS 0-RTT в actual caller? **R02-21**: теряется ли VerifyConnection в ShadowTLS default conversion и достигается ли она в composed caller? |
| Короткий вывод | R02-20: `quic.DialEarly` есть в caller, но без ClientSessionCache резюмирование/0-RTT невозможны — HY2-пароль всегда 1-RTT; replay-вопрос растворяется, остаётся серверная QUIC Initial/amplification поверхность. R02-21: lossy conversion реальна (VerifyConnection/ClientSessionCache/ECH не копируются), но v3+utls Snowden-композиция идёт через WithSessionIDGenerator-ветку и её не достигает |
| Статус | **READY_FOR_REVIEW**; дата среза 26.10.2026 |
| Evidence | Source-факты local module cache (go.mod exact pins) + stdlib reference + Snowden render; web primary RFC/blog. Никакого crypto/TLS/QUIC/wire исполнения |
| Область / дата | 26 октября2026; core1.13.19/b5ebaa1f…, sing-quic v0.6.4-0.20260803…, quic-go v0.59.0-sing-box-mod.4, sing-shadowtls0.2.1, Go1.26.7 reference, render.go актуален на дату среза |
| Предпосылки | Snowden render не меняет TLS-опции HY2 (нет utls/кэша) и shadowtls (utls chrome); production tags with_utls сохраняются; stdlib gate совпадает с прочитанной версией Go |
| Сильная альтернатива | «DialEarly в caller ⇒ 0-RTT включён» — опровергнут stdlib gate (handshake_client.go:358). «ShadowTLS теряет VerifyConnection у Snowden» — опровергнуто ветвлением outbound.go:57-62 |
| Ready reuse | Текущий рендер не менять; инварианты задокументировать (нет кэша HY2; shadowtls только utls). ClientSessionCache на HY2 — только вместе с серверным anti-replay/multi-instance кэшем |
| Reject / цена | Не включать session cache ради экономии одного RTT; не строить STD shadowtls v3 с donor-pinning callback; не считать Salamander защитой от Initial replay (это обфускация, не аутентификация датаграмм) |
| Следствие для системы | Адресат FR/TH-owner: replay-cache требования не нужны для текущего HY2 контракта; возникают условно при future resumption. Граница совместимости shadowtls STD — в design-note |
