## Предлагаемые решения

- Независимый gate должен быть расположен до first execution candidate;
  startup self-check нового кода не защищает от actor, уже контролирующего этот
  код через разрешённый OS install channel. Уточнить channel threat promises.
- Различать flat final-artifact digest, platform signature/lineage, installed
  set, executing incarnation и adopted owner/readiness. Для Play upload/AAB
  не считать final APK/app signing identity; для Android rotation учитывать OS.
- Дорабатывать existing Windows custody/adoption boundaries, не создавать их
  копию. Public pair installer уже source-blocked до native acceptance.
- Recover files отдельно от trust progress/floors. Старый binary не становится
  допустимым от rollback, если уже ниже актуальной security floor.
