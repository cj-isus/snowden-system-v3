# R05-001 — доверие, история и право на применение

2026-10-25. **READY_FOR_REVIEW**.

## Входы и результат

- [REPORT](../REPORT.md): два уточнения, state machine и 15 конечных будущих cases.
- [SOURCES](../SOURCES.md): точные pins/licenses, происхождение и пределы reuse.
- Captures: `.artifacts/research/theory-05/R05-001/`, 27 локальных snapshots,
  `local-inputs.json`, `upstream-inputs.json` и GitHub ref/release records.
- Входы не включают секреты/реальные профили или raw user logs. Проверок кода,
  native/OS/live поведения, signatures или SDK conformance не выполнялось.

## Нужные решения по выводам

| Вывод | Предлагаемое решение | Почему |
|---|---|---|
| R05-001-A | Рассмотреть уточнение OP-03 и T07 до реализации seam | Intermediate pointer + error не равен persistable authority. Нужно сохранить допустимые predecessor steps, различая их и новый rejected expired объект |
| R05-001-B | Принять domain-aware retention как design requirement; B1 направить на будущую адресную проверку | Key rotation может разрешать dependent TUF-cache invalidation. Без этого «монотонность» блокирует recovery; application floors не сбрасываются |

Это предложения, **не ACCEPTED**. Трактовка SDK/progress уточняется на основе
спецификации, не исправлением общей теории этим форком.

## Передача в разработку после научного review

1. TH-03 / AND-04-S4b T05–T11: определить допустимые persisted transitions,
   partial-error provenance и role-reset scope; выбрать один portable seam.
2. Windows owner: проверить conditional B1 на captured loadRoot/loadTimestamp
   path; Android owner: интегрировать только принятый production contract.
3. Отдельное разрешение на semantic cases, затем durability/native/device
   gates. Plan-only и открытые product requirements этим пакетом не закрываются.

Прямых сообщений другим чатам нет. REPORT/SOURCES/свой STATE и captures —
единственные изменяемые области. SDK, планы и общий сборник теории сохранены.

## Актуальность

Ручная сверка выполнена: pins/лицензии/причины сохранения/границы reset,
положительные и отрицательные cases, отсутствие runtime claims. Источники
связаны reference links в REPORT, относительные пути к пакету существуют.
Это самопроверка автора, независимой рецензии пока нет.

Из 27 локальных inputs изменился Android ADR-017: добавлены четыре вводные
строки с маршрутом к ADR-032 (preview/share journal). Diff просмотрен;
TUF block не менялся, A/B не затронуты. `drift.json` сохраняет оба digest;
captured input не подменён новым. Прочие 26 input hashes совпали при сверке.

24 upstream captures включают публичные source/лицензии/HTML и ref metadata;
это не число независимых исследований. `review.md` в artifacts фиксирует
границы самопроверки. Решение по A/B и формулировке OP-03/T07 требуется отдельно,
до реализации portable seam.
