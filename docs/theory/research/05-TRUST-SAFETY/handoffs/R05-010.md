## R05-010-D — основание retention timestamp

R05-010-D основан на source-срезе **27 октября 2026**. Итог оформлен
**28 октября после cutoff**; своевременная сдача D и финальная проверка source
freshness **не подтверждены** (`PARTIAL_AT_CUTOFF` по оформлению).
Это ограничение evidence, а не новое исследование или продление среза.

Рецензия руководителя [R05-010-A](../../reviews/NINE-2026-10-27-R05-010-A.md)
принимает только timestamp→returned-Progress conditional A, **не D**.

| Поле | R05-010-D — минимальное основание retention timestamp |
|---|---|
| Ответ | У current full updater нет публичного timestamp-step receipt. Доступны Timestamp и RefTime; вывод ограниченно восстанавливается по exact pinned порядку checks и provenance, не по имени TrustedMetadata |
| Готовое API / критерий | REPORT§7: exact-byte/source/continuity/reset/owner guards G и отдельно H — known previously accepted predecessor, либо F — strict Expires>того же SDK RefTime для связанного SDK-owned timestamp и root. Достаточное условие ограничительного сохранения `G ∧ (H ∨ F)`; **не** новое permission на артефакт |
| Почему F ограниченно полезен | В pinned UpdateTimestamp assignment151 следует type/signature/version/reference/root checks; единственный post-assignment final check — expiry. Привязка к неизменённому SDK state существенна. Для snapshot остаётся ещё version-link check — criterion не переносится |
| Старый predecessor | При known prior acceptance, правильной lineage и отсутствии invalidating reset старый B сохраняет историческое значение даже после expiry. File presence/State.Validate/equal version не prior-acceptance receipt |
| Новый rejected pointer | Новый expired C, не равный допустимому B, не проходит F; его не называют accepted progress. Сам pointer и fetch-delivery не достаточны |
| Persist error / tail error | Final timestamp predicate может пройти до I/O failure либо позже snapshot/targets error. Отдельное platform retention допустимого progress возможно; successful disk write остаётся unknown. Общий Refresh error запрещает новый artifact, но не стирает predecessor |
| Контрпример | Previously accepted B теперь expired; remote same-version candidate: equal-version branch до assignment превращается в normal loadTimestamp return, но B остаётся expired. Ни `loadTimestamp==nil`, ни новый same-version input не обновляют полномочие B |
| Цена и предпосылки | Value-only predicate и provenance-развилка без собственной криптографии; exact go-tuf2.4.2 semantic pin, immutable SDK pointers/RefTime и domain-aware reset. SDK change требует review; generic receipt/durable guarantee не появляется |
| Статус | Авторский D — READY_FOR_REVIEW в пределах сохранённого source/model текста; независимой приёмки D нет; end-of-window source freshness **не подтверждена** |
