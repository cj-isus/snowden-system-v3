# R06-007 — IPv6-only/NAT64: bootstrap и достижимое восстановление

Дата: **2026-10-26**. Статус: **READY_FOR_REVIEW**, не ACCEPTED/product PASS.
[REPORT §31…35](../REPORT.md), [SOURCES §8](../SOURCES.md).

## Новизна и доказательства

Windows preflight дляvless+ws domains выбирает publicIPv4; явные resolver/DoH
targets IPv4, DoH query type=A. IP literals обходят DNS; generic ParseIP/cache
может принятьIPv6, поэтому универсальный «IPv6 не поддерживается» не заявлен.
Renderer сохраняет domain TLS/WS identity при numeric override. Недоступность
такого bootstrap path не равна global VPS failure; prefer_ipv6 сам не исправляет
IPv4-literal bootstrap/forced target. Реальный cache/env/settings не читались.

Android NAT64 prefix входит в physical context fingerprint, но это не usable
translator receipt. Local DNS bridge явно закрыт до accepted resolver policy.
IPv4 inner TUN/optional IPv6 capture не требует IPv4 physical underlay; capture
не ослабляется для обхода bootstrap. Existing bound-socket/epoch/authority gates
сохраняются. Native/device support не установлен.

Conditional graph различает nativeIPv6, IPv4 route/CLAT, FQDN DNS64 и явно
admitted local synthesis. Logical peer E, physical D, prefix/context/resolver
имеют разные authority/сроки. Prefix не обязательно64:ff9b::/96, не следует
жёстко concatenation-ить IPv4 или менять managed/Private DNS на public.

## Primary reuse / ограничения

Public RFC6147/6877/6052/8305 TXT получены с hashes; просмотрены DNS64 vs CLAT,
encoding и Happy Eyeballs §7 literal/brokenAAAA/VPN split-DNS. Reference алгоритмы,
не новый translator/SDK и не measured timing targets. Project existing
prepare/renderer/guard/probe/physical context переиспользуются в предложении.

sing-box resolve.go versioned cache: domain lookup/race vs numeric lower-dialer
path. Новый immutable raw comparison timeout; external bytes не объявлены
confirmed. LinkProperties API page/RFC7050 retrieval тоже timeout; specific
discovery algorithm не выдан за reviewed. Пределы приведены в SOURCES.

## Практическое применение

Сначала closure/identity/admission contract перед AF race; source bridge не
допускает бесконтрольный system DNS. Показать конкретный network/bootstrap gap,
не банить VPS/все сети по одному family failure. Допустимые user actions:
сохранить живой путь, accepted alternate endpoint/OS translation или согласованная
другая сеть; иначе issuer/IT. Call/RDP и remote transaction outcome отдельны.
