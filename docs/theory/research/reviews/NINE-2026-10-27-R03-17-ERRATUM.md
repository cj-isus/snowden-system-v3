## 1. Произвольная зависимость: сумма, а не произведение

В [REPORT §18.1](../03-ADAPTATION/REPORT.md#181-r03-17--трёхслойный-контракт-registration--bound--identification)
формула `FWER ≤ 1-(1-α)^W` названа worst case при неизвестной зависимости.
**Это неверно.**

Пусть E_j — событие хотя бы одной ложной декларации для j-го истинного нуля,
а его вероятность не больше α_j. Для фиксированного конечного семейства:

\[
\operatorname{FWER}=P\!\left(\bigcup_{j=1}^{W}E_j\right)
\le \min\!\left(1,\sum_{j=1}^{W}P(E_j)\right)
\le \min\!\left(1,\sum_{j=1}^{W}\alpha_j\right).
\]

Доказательство: индикатор объединения не больше суммы индикаторов;
математическое ожидание сохраняет неравенство. Независимость не требуется.
При одинаковых α_j=α получаем `min(1,Wα)`.

Для **независимых событий ошибок** имеем
`P(∪E_j)=1-∏(1-P(E_j)) ≤ 1-(1-α)^W`. Независимость самих проверяемых
гипотез — не то же самое, что независимость этих событий.

**Опровергающий пример:** два несовместимых события E_1/E_2 вероятности 0.05.
Их объединение имеет вероятность 0.10, которая **больше**
`1-0.95²=0.0975`. Если события совпадают, объединение имеет вероятность 0.05.
Зависимость не обязана только уменьшать границу, выбранную по независимости.
Числа здесь — иллюстрация доказательства, не эксперимент и не оценка сети.

## 2. «+1 попытка за успех» не доказывает бесконечное ожидание

Прежний §18.2 утверждал: при любом α>0 положительный дрейф и неограниченное
ожидаемое число ложных успехов. Для описанного механизма этого не следует.

Контрпример достаточен, чтобы отвергнуть универсальность: в начале есть W
кредитов; каждая попытка тратит один, независимый ложный успех вероятности
`0<α<1` возвращает один. При A_t>0:

\[
A_{t+1}=A_t-1+S_t,\qquad S_t\sim\operatorname{Bernoulli}(\alpha).
\]

Тогда `E[A_{t+1}-A_t]=α-1<0`. Работа заканчивается на W-м неуспехе.
Ожидание числа попыток — `W/(1-α)`, ложных успехов — `Wα/(1-α)`, оба конечны.
Это отрицательно-биномиальное ожидание можно получить как сумму W независимых
геометрических времен до следующего неуспеха.

При иной схеме пополнения, реальных успехах, зависимости и нестационарности
результат может измениться. Поэтому сначала задаётся механизм, а не объявляется
«ветвящийся процесс с положительным дрейфом». Конечное ожидание само по себе
не доказывает желаемую статистическую или физическую безопасность алгоритма.

## 3. Неизвестное заранее число гипотез не делает контроль ошибок невозможным

Возможен последовательный бюджет: до запуска j-й проверки выбирается
неотрицательный α_j по доступной прошлой информации. Если для всей j-й
anytime-проверки, условно на эту информацию, вероятность E_j не больше α_j,
и `∑α_j ≤ δ` почти наверное, то:

\[
P(\exists j:E_j)\le E\!\left[\sum_j\mathbf1_{E_j}\right]
\le E\!\left[\sum_j\alpha_j\right]\le\delta.
\]

Для неотрицательных слагаемых переход к счётному семейству допускается
монотонной сходимостью. Пример заранее определённого расходования:
`α_j=δ/[j(j+1)]`; сумма равна δ по телескопированию.

**Ключевая предпосылка — условная валидность каждой проверки при фактическом
адаптивном выборе**, а не просто наличие per-claim CI в библиотеке. Число
проверок может быть случайным; сам этот факт не опровергает гарантию.
Произвольная повторная проверка с тем же α или смена family после просмотра
результатов гарантию таким рассуждением не получает.

## 4. Что сохраняется как инженерное предложение

- Учёт всех попыток и прекращённых/неполных исходов нужен для заявленного
  denominator и последующего разбора, но один журнал не доказывает отсутствие
  скрытых попыток, истинность гипотез или регистрацию раньше наблюдения.
- Физические лимиты времени/RAM/сети, статистический бюджет ошибок и полномочия
  на применение рекомендации — три разных ограничения.
- Обычные источники по Вальду/Ширяеву/Воронцову нельзя цитировать как проверенное
  доказательство конкретной формулы, пока не прочитаны нужные определения и
  условия. Предыдущие библиографические ссылки не подтверждают ошибочные выводы.
- Регистрация всех классов задач сама по себе не исправляет selection/censoring
  и не делает task outcome наблюдаемым. R06-011 и новый R06-013 должны отделять
  эти предпосылки от статистического метода.
