| ID / вопрос | **R04-011-A/B/C**: что в Android power policy реально даёт VPN FGS; что означает 10s HY2 keepalive; покрывает ли готовый OSS pause caller таймер HY2? |
| Короткий вывод | **A:** foreground VPN UID в Android16 source освобождается от ordinary Doze/App-standby network blocks, но FGS/systemExempted не является wake lock, power allowlist или LPS exemption. **B:** HY2 10s — input receive/PTO timer: `D=lastRx+max(min(10s,idle/2),1.5*PTO)`; due→queue→socket→wire distinct, so not a fixed radio/battery rate. Explicit Go1.26/arm64 reference excludes suspend; shipped Android artifact unknown. **C:** SFA Doze receiver calls libbox PauseManager, but searched pinned source proves a URL-test ticker subscriber, not direct HY2/quic-go timer suppression |

| Сильный контрпример | LPS explicitly restricts foreground-service apps; FGS without wake lock need not execute timers in deep suspend.
