## Практический порядок предложений

1. Сохранить existing transport timer machinery и Android elapsed authority fences.
   В observation contract назвать clock domain/unit/boot/owner/network epoch.
2. Развести local TUN CPU/packet counters, outer carrier, actual wire/remote receipt
   и useful application response. Не рисовать readiness по local TCP ACK.
3. После разрешения владельцам: finite suspend/awake-pause/local-vs-outer cases
   на exact artifact. Только затем один optional batching или supported HY2 seam.

NAT lifetime ограничивается actual refresh gaps, не K-config. Optional coalescing
допустимо внутри совместимых release/deadline windows; textbook interval-cover
greedy здесь только narrow model, не доказанный energy optimum реального VPN.
Public IPsec NAT-T SocketKeepalive не offload QUIC PING; постоянный wake lock
и дополнительный app ping не обоснованы как готовое улучшение.
